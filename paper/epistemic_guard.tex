\begin{abstract}
Tool-using language-model agents deployed over the Model Context Protocol (MCP) suffer from three coupled runtime verification gaps: (i) \emph{action fabrication}, where post-tool prose narrates side effects that failed, timed out, or never executed; (ii) \emph{provenance collapse}, where unverified model narration or web-retrieved text is persisted into durable agent memory on equal footing with executed tool outputs; and (iii) \emph{syndicated echo amplification}, where mirrored web content satisfies multi-source corroboration thresholds from a single upstream origin. Existing MCP firewalls authenticate wire calls at the transport boundary, while prompt-level guardrails consume multi-gigabyte GPU memory without cryptographically binding prose claims to executed tool receipts. We present \texttt{epistemic-guard} (v0.4.3), an open-source runtime verification library and out-of-process \texttt{stdio} MCP receipt proxy implemented in Python across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L24}{15} modules with \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L32}{0}\,MiB GPU VRAM overhead. \texttt{epistemic-guard} isolates Ed25519 signing keys outside the agent process, records RFC\,6962 SHA-256 Merkle audit chains with bidirectional AER-1 receipt translation, supervises post-turn prose via \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L10}{4} OpenVINO INT8 encoders (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L28}{279.48}\,MB unpacked), enforces SQLite write-gating across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L22}{7} provenance domains, and collapses syndicated RAG mirrors prior to hazard-tiered corroboration. Across deterministic protocol conformance suites, \texttt{epistemic-guard} achieves \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L25}{100.0\%} tamper rejection across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L24}{200} Merkle receipts, \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L20}{100.0\%} wire verification across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L16}{40} fault-injected MCP calls with \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L10}{0} child-environment key leaks, and \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L40}{100.0\%} blocking on \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L38}{100} unauthorized memory writes. On an external held-out benchmark of \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L59}{250} tool-turn prose traces, \texttt{epistemic-guard} reaches \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L23}{94.4\%} accuracy at \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L34}{27.38}\,ms median CPU latency, outperforming 12B--14B GPU judge baselines by \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L4}{7.6}--\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L5}{8.0} percentage points at \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L7}{2.74}--\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L6}{2.84}$\times$ lower median latency.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Autonomous software engineering, customer-operations, and data-analysis agents increasingly invoke external tools through standardized JSON-RPC transports such as the Model Context Protocol (MCP)~\cite{mcp2025spec}. While transport standardization simplifies tool integration, it leaves an architectural gap between \emph{what actually happened on the wire} and \emph{what the language model tells the user or writes to persistent state}. In production agent loops, tool calls routinely return HTTP errors, time out, fail schema validation, or remain uninvoked while the language model produces fluent first-person prose claiming that the state-mutating action succeeded~\cite{maxwell2026evasion}. When downstream workflows or persistent memory stores ingest those unverified claims, transient hallucinations harden into durable state corruption~\cite{greshake2023indirect,maxwell2026poisoning}.

From a runtime verification perspective~\cite{leucker2009brief,bartocci2018lectures}, closing this gap requires enforcing three invariants across the agent turn lifecycle without trusting the agent's own address space or allocating dedicated GPU accelerators:
\begin{enumerate}
  \item \textbf{Boundary-Attested Execution Receipts:} Every tool call and response traversing the MCP boundary must be cryptographically signed out-of-process, distinguishing transport-level non-execution (\texttt{executed=false}) from application-level tool failure (\texttt{executed=true, ok=false}).
  \item \textbf{Receipt-Bound Prose Supervision:} Before an assistant response is emitted to a user or downstream orchestrator, state-mutating action claims in natural language must be matched against cryptographically verified execution receipts from the current turn.
  \item \textbf{Provenance-Gated Persistence and De-Syndicated Corroboration:} Durable memory stores must reject unsigned or narration-sourced writes at the storage boundary, and retrieval-augmented generation (RAG) pipelines must collapse syndicated web copies before evaluating multi-source corroboration for high-hazard claims.
\end{enumerate}

These failure classes map directly onto the OWASP Top 10 for Agentic Applications~\cite{owasp2026agentic}: Tool Misuse and Unverified Action Claims (\texttt{ASI02}), Memory and Context Poisoning (\texttt{ASI06}), and Cascading Inter-Component Hallucinations (\texttt{ASI08}). Existing open-source defenses address isolated slices of this surface. Transport firewalls such as Pipelock~\cite{pipelock2026} scan MCP egress traffic and emit mediator-signed receipts on the wire, and sandboxed runtimes such as NabaOS~\cite{nabaos2026} enforce Ed25519-signed policy constitutions, but neither supervises post-turn natural-language prose for ungrounded action claims nor enforces syndicated-source deduplication before memory commit. Conversely, dialogue guardrails such as NeMo Guardrails~\cite{rebedea2023nemo}, Llama Guard~\cite{inan2023llamaguard}, and Guardrails AI~\cite{guardrailsai2024} inspect text using conversational rails or multi-billion-parameter LLM judges that require \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L50}{8,844}--\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L66}{12,214}\,MiB of GPU VRAM and lack cryptographic tool-receipt attestation.

This paper presents the software architecture, formal runtime contracts, and reproducible empirical evaluation of \texttt{epistemic-guard} (v0.4.3), a lightweight runtime verification middleware for Python and MCP agent stacks~\cite{maxwell2026seed,maxwell2026fivelayer}. Our contributions are:
\begin{itemize}
  \item \textbf{Out-of-Process MCP Receipt Proxy (\texttt{mcp-proxy}):} A transparent \texttt{stdio} JSON-RPC\,2.0 mediator that strips signing secrets from child server environments, classifies \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L13}{4} distinct execution and error states, appends Ed25519-signed receipts to an append-only JSONL Merkle audit log with public-key pinning, and interoperates losslessly with the Agent Execution Receipt (\texttt{AER-1}) wire format~\cite{zambo2026aer1}.
  \item \textbf{Zero-VRAM INT8 Receipt Supervision:} A hybrid symbolic--neural supervisor (\texttt{ReceiptSupervisor}) combining \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L10}{4} OpenVINO INT8 transformer encoders (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L28}{279.48}\,MB total on disk, \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L32}{0}\,MiB GPU VRAM) with receipt ledger verification to block fabricated side-effect narration at \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L34}{27.38}\,ms median CPU latency.
  \item \textbf{Provenance-Gated SQLite Store \& Syndication-Aware RAG Filter:} Domain-separated HKDF-SHA256~\cite{krawczyk2010rfc5869} + Ed25519~\cite{josefsson2017rfc8032} write-gating with SQL immutability triggers, paired with MinHash/SimHash shingle deduplication~\cite{broder1997resemblance,charikar2002similarity} and a \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L20}{12}-cell hazard-tiered corroboration lattice.
  \item \textbf{Audit-Traceable Empirical Evaluation:} A deterministic evaluation artifact audited via \texttt{osaudit} where every empirical figure in this manuscript resolves to cryptographic input hashes and reproducible JSON outputs.
\end{itemize}

\section{Threat Model and Verification Scope}
\label{sec:threat}

\paragraph{System Model.}
We consider an autonomous agent process $\mathcal{A}$ interacting with one or more external MCP tool servers $\{\mathcal{S}_1, \dots, \mathcal{S}_k\}$, a web/RAG retrieval pipeline $\mathcal{R}$, and a persistent local memory database $\mathcal{M}$. During turn $t$, $\mathcal{A}$ emits zero or more JSON-RPC\,2.0 \texttt{tools/call} requests, observes responses or transport faults, optionally retrieves external web documents, writes candidate state facts to $\mathcal{M}$, and emits a natural-language response $y_t$ to the user.

\paragraph{Adversary and Fault Assumptions.}
We consider both stochastic model failures and adversarial indirect prompt injections~\cite{greshake2023indirect} embedded inside tool outputs or retrieved web documents:
\begin{enumerate}
  \item \emph{In-process agent untrustworthiness (\texttt{ASI02}, \texttt{ASI08}):} The agent process $\mathcal{A}$ (or injected prompt context controlling $\mathcal{A}$'s generation) may claim in $y_t$ that a side-effecting tool call succeeded when no call occurred, when the server returned \texttt{isError=true}, or when the child process crashed mid-flight. If signing keys reside inside $\mathcal{A}$'s environment variables or memory space, compromised code or tool plugins sharing that process could forge execution receipts.
  \item \emph{Cross-session memory poisoning (\texttt{ASI06}):} $\mathcal{A}$ may attempt to persist unverified assistant narration (\texttt{LLM\_NARRATION}) or untrusted prompt text into $\mathcal{M}$ as verified facts, or mutate historical audit rows via SQL \texttt{UPDATE}/\texttt{DELETE} statements.
  \item \emph{Syndicated corroboration spoofing (\texttt{ASI06}, \texttt{ASI08}):} Retrieved web pages frequently reproduce identical wire-service copy, scraped documentation, or coordinated SEO mirrors across distinct hostnames. Naive multi-URL counting treats \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L49}{3} mirrors of a single rumor as independent corroboration for high-hazard medical, financial, or security claims.
\end{enumerate}

\paragraph{Trusted Computing Base (TCB) and Non-Goals.}
The TCB comprises the host OS kernel, the out-of-process \texttt{epistemic-guard mcp-proxy} binary/process holding the master seed, the pinned SHA-256 digests of the \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L19}{16} INT8 model files, and the SQLite database file permissions. We do \emph{not} attempt to prevent kernel-level rootkits on the host machine, guarantee semantic correctness of an upstream external API that returns a successful status code with factually erroneous business data, or replace network egress allowlists (for which \texttt{epistemic-guard} composes cleanly alongside proxies such as Pipelock~\cite{pipelock2026}).

\subsection{Domain-Separated Cryptographic Provenance and AER-1 Receipts}
\label{sec:crypto}

Rather than sharing a single symmetric token across components, \texttt{provenance.py} derives \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L8}{5} domain-isolated Ed25519~\cite{josefsson2017rfc8032} keypairs (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L3}{32}-byte keys, \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L4}{64}-byte signatures) from a high-entropy master seed via RFC\,5869 HKDF-SHA256~\cite{krawczyk2010rfc5869} using explicit context labels across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L22}{7} enumerated provenance domains (\texttt{Provenance}): \texttt{TOOL\_OUTPUT}, \texttt{USER\_EXPLICIT}, \texttt{SYSTEM\_VERIFIED}, \texttt{WEB\_CORROBORATED}, \texttt{DERIVED\_SUMMARY}, \texttt{LLM\_NARRATION}, and \texttt{UNTRUSTED\_EXTERNAL}. Crucially, \texttt{SignerFactory} intentionally omits signing constructors for \texttt{LLM\_NARRATION} and \texttt{UNTRUSTED\_EXTERNAL}: unverified model prose cannot produce a valid provenance envelope even via accidental API misuse.

Each tool invocation produces a canonical \texttt{ToolReceipt} recording the request ID, tool name, canonical JSON SHA-256 digests of arguments and outputs, execution boolean (\texttt{executed}), outcome boolean (\texttt{ok}), error code, latency, and UTC timestamp. Receipts are chained into an RFC\,6962~\cite{laurie2013rfc6962} domain-separated Merkle tree (\texttt{0x00} leaf prefix, \texttt{0x01} interior node prefix) supporting logarithmic inclusion proofs and deterministic tamper detection. To interoperate with multi-vendor agent ecosystems, \texttt{epistemic-guard} implements lossless bidirectional translation (\texttt{to\_aer1\_dict}, \texttt{verify\_aer1\_dict}) for the \texttt{AER-1} (\texttt{draft-zambo-aer1}) receipt specification~\cite{zambo2026aer1}, verifying both detached Ed25519 signatures and canonical SHA-256 payload digests.

\subsection{Out-of-Process \texttt{stdio} MCP Receipt Proxy}
\label{sec:proxy}

In-process Python decorators (\texttt{ReceiptLedger}) protect benign agent loops against hallucinated actions, but share memory and environment variables with the agent runtime. For untrusted or prompt-injected runtimes, \texttt{epistemic-guard mcp-proxy} interposes as an out-of-process \texttt{stdio} parent between the MCP host (e.g., Claude Desktop, Cursor, or custom MCP clients) and any downstream MCP tool server:
\begin{enumerate}
  \item \textbf{Secret Scrubbing:} Before spawning the child MCP server, \texttt{mcp-proxy} strips \texttt{EPISTEMIC\_GUARD\_MASTER\_KEY} and signing key material from the child's environment block so compromised child servers cannot forge receipts.
  \item \textbf{Four-State Wire Classification:} As JSON-RPC\,2.0 frames stream over \texttt{stdin}/\texttt{stdout}, \texttt{mcp-proxy} correlates \texttt{tools/call} requests by JSON-RPC \texttt{id} and distinguishes \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L13}{4} runtime outcomes: (a) normal tool success (\texttt{executed=true, ok=true}); (b) application-level MCP tool error where \texttt{result.isError=true} (\texttt{executed=true, ok=false}); (c) protocol-level JSON-RPC error frame (\texttt{executed=false, ok=false}); and (d) child server crash or EOF mid-call (\texttt{executed=false, ok=false, EOF\_MID\_CALL}).
  \item \textbf{Key-Pinned Append-Only Audit Log:} Signed entries are flushed immediately to a chain-linked JSONL log whose header pins the Ed25519 public verification key; \texttt{verify-log} rejects both payload mutation and key-substitution attacks on reopen.
\end{enumerate}
In addition to \texttt{mcp-proxy}, \texttt{epistemic-guard mcp-server} exposes \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L11}{4} verification tools directly over MCP across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L25}{3} protocol revisions (\texttt{2024-11-05}, \texttt{2025-03-26}, and \texttt{2025-06-18}).

\subsection{Hybrid Symbolic--Neural Post-Turn Prose Supervision}
\label{sec:supervision}

Regex-only action supervisors suffer high false negatives when models paraphrase state mutations using indirect phrasing, nominalizations, or passive voice, whereas pure zero-shot NLI encoders suffer catastrophic false positives on benign conversational statements~\cite{maxwell2026evasion}. \texttt{ReceiptSupervisor} resolves this tension via a two-stage CPU pipeline backed by \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L10}{4} OpenVINO INT8 models (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L19}{16} SHA-256-pinned files totaling \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L28}{279.48}\,MB, distributed via Hugging Face Hub with GitHub Releases fallback):
\begin{enumerate}
  \item \textbf{Structured Action-Claim Detection:} Candidate assistant sentences are scored by the INT8 \texttt{action\_claim} transformer (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L13}{82.67}\,MB) alongside lexical speech-act guards that exempt hedged disclaimers, future intent, and explicit failure reports. If no completed external side effect is asserted, the turn passes immediately without requiring receipts.
  \item \textbf{Cryptographic Receipt Matching \& NLI Grounding:} When a side-effect claim is detected, \texttt{ReceiptSupervisor} inspects the turn's verified \texttt{ToolReceipt} set: every receipt signature is checked against \texttt{VerifierKeyring}, receipts with \texttt{executed=false} or \texttt{ok=false} are excluded from grounding success claims, and the DeBERTa-v3~\cite{he2023debertav3} INT8 cross-encoder (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L15}{91.1}\,MB) verifies semantic entailment between serialized receipt outputs and claimed outcomes. Ungrounded claims return a structured \texttt{REPAIR} verdict listing exact violation spans so the orchestrator can re-prompt or redact before user delivery.
\end{enumerate}

\subsection{Provenance-Gated SQLite Memory and De-Syndicated RAG}
\label{sec:memory}

\paragraph{Storage-Boundary Write Gate.}
\texttt{ProvenanceStore} (\texttt{store.py}) wraps SQLite persistence behind a mandatory cryptographic envelope check. Only \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L5}{5} provenance domains with valid detached Ed25519 signatures are write-eligible; writes carrying \texttt{LLM\_NARRATION}, \texttt{UNTRUSTED\_EXTERNAL}, forged keys, or mutated payloads raise \texttt{UnauthorizedProvenanceError} before touching SQLite. Accepted envelopes are linked into a cumulative SHA-256 chain digest and protected by \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table2_conformance.json\#L34}{2} SQL \texttt{BEFORE UPDATE} and \texttt{BEFORE DELETE} triggers that abort in-place mutation of committed provenance records.

\paragraph{Syndication Deduplication and Hazard-Tiered Corroboration.}
Before web-retrieved claims can attain \texttt{WEB\_CORROBORATED} provenance, \texttt{corroboration.py} normalizes candidate passages into word shingles of width $k=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L23}{5}$, filters non-evidentiary boilerplate via the MiniLM~\cite{wang2020minilm} INT8 \texttt{web\_evidence} encoder (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L16}{23.06}\,MB), and clusters near-duplicate mirrors using MinHash Jaccard resemblance~\cite{broder1997resemblance} and SimHash fingerprints~\cite{charikar2002similarity} alongside registrable-domain grouping. Independent source clusters are mapped into \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L2}{4} corroboration buckets and evaluated against a \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L7}{3}-tier hazard classifier (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L14}{82.65}\,MB; \texttt{LOW}, \texttt{ELEVATED}, \texttt{HIGH}) crossed with \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L21}{4} epistemic proof standards (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L20}{12} policy cells total). High-hazard claims backed solely by syndicated copies of a single origin collapse to a single independent cluster and are deterministically denied promotion.

\section{Empirical Evaluation}
\label{sec:eval}

We structure our evaluation around two research questions:
\begin{itemize}
  \item \textbf{RQ1 (Cryptographic \& Wire-Protocol Conformance):} Do the Merkle receipt ledger, \texttt{AER-1} interop layer, out-of-process \texttt{mcp-proxy} fault classifier, SQLite provenance gate, and RAG syndication filter uphold their security invariants with zero false accepts and zero secret leakage under adversarial fault injection?
  \item \textbf{RQ2 (Held-Out Prose Supervision Accuracy \& Resource Cost):} How accurately and rapidly does \texttt{ReceiptSupervisor} detect ungrounded post-turn action claims on held-out traces compared with 12B--14B parameter GPU LLM judges and pure CPU NLI baselines?
\end{itemize}

All experiments are deterministic, version-pinned, and audited with \texttt{osaudit} provenance manifests (\texttt{results/table1\_architecture.json}, \texttt{results/table2\_conformance.json}, and \texttt{results/table3\_heldout\_supervision.json}). Confidence intervals for binomial proportions use the two-sided \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/osaudit.toml}{95\%} Wilson score interval~\cite{wilson1927probable}.

\section{Limitations and Threats to Validity}
\label{sec:limitations}

\paragraph{Internal Validity.}
Protocol conformance workloads in Table~\ref{tab:conformance} exercise real child processes, real Ed25519/HKDF primitives, and real OpenVINO INT8 inference, but use deterministic synthetic payloads rather than live third-party SaaS endpoints so that independent auditors can rerun \texttt{osaudit results --rerun} offline without API credentials or non-deterministic network drift.

\paragraph{External Validity.}
Our held-out supervision benchmark ($N=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L59}{250}$) evaluates English-language assistant prose across software engineering, productivity, and state-mutation tools. Multilingual prose, code-only patches without natural-language narration, or domain-specific idiomatic phrasing outside standard tool-use distributions may exhibit higher false negative or false positive rates (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L29}{4} false negatives and \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L30}{10} false positives observed on English held-out splits).

\paragraph{Construct and Transport Scope.}
First, \texttt{mcp-proxy} in v0.4.3 mediates \texttt{stdio} MCP transports; Streamable HTTP/SSE remote MCP servers currently require local \texttt{stdio} bridging or SDK-level \texttt{ReceiptLedger} integration. Second, cryptographic receipts attest that a downstream server returned \texttt{ok=true} with a specific output digest---they cannot verify whether an external API lied about committing a side effect internally. Third, MinHash/SimHash shingle deduplication ($k=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table1_architecture.json\#L23}{5}$) reliably collapses verbatim and lightly edited wire-service syndication, whereas deep LLM-rewritten paraphrases of a single false rumor with low lexical overlap can evade surface shingling and require upstream source-reputation lists.

\section{Related Work}
\label{sec:related}

\paragraph{MCP Firewalls and Cryptographic Agent Runtimes.}
Pipelock~\cite{pipelock2026} provides an open-source Go egress proxy and MCP firewall that scans outbound tool parameters for prompt injection or DLP leaks and emits Ed25519 mediator-signed action receipts conforming to \texttt{AER-1}~\cite{zambo2026aer1}. NabaOS~\cite{nabaos2026} enforces sandboxed execution governed by Ed25519-signed YAML constitutions. \texttt{epistemic-guard} is complementary to transport firewalls: whereas Pipelock secures the pre-execution network perimeter, \texttt{epistemic-guard} interoperates natively with \texttt{AER-1} receipts while adding post-turn natural-language prose supervision (\texttt{ReceiptSupervisor}), domain-separated SQLite memory write-gating, and syndicated RAG corroboration collapse.

\paragraph{Conversational Guardrails and LLM-as-a-Judge.}
NeMo Guardrails~\cite{rebedea2023nemo} compiles programmable Colang dialogue rails; Llama Guard~\cite{inan2023llamaguard} fine-tunes multi-billion-parameter safety classifiers for toxicity and policy harms; and Guardrails AI~\cite{guardrailsai2024} composes output validators for structural and semantic constraints. Unlike toxicity moderation or unconstrained LLM-as-a-Judge pipelines requiring \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L50}{8,844}--\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L66}{12,214}\,MiB of GPU memory, \texttt{epistemic-guard} targets epistemic state consistency between cryptographically signed wire execution logs and user-facing narration in \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L32}{0}\,MiB VRAM.

\paragraph{Classical Runtime Verification and Provenance Security.}
Runtime verification synthesizes monitors that observe execution traces against formal safety properties~\cite{leucker2009brief,bartocci2018lectures}, while Certificate Transparency~\cite{laurie2013rfc6962} established append-only Merkle audit logs for untrusted intermediaries. Indirect prompt injection research~\cite{greshake2023indirect} and agent memory poisoning analyses~\cite{maxwell2026poisoning,maxwell2026fivelayer} demonstrate that collapsing untrusted data and verified execution state into a single context or vector store enables persistent cross-session compromise (\texttt{ASI06}~\cite{owasp2026agentic}). \texttt{epistemic-guard} operationalizes classical monitor separation and Certificate Transparency audit trees as a drop-in Python and MCP developer primitive.

\section{Conclusion}
\label{sec:conclusion}

We presented \texttt{epistemic-guard} (v0.4.3), an open-source runtime verification middleware that couples out-of-process \texttt{stdio} MCP receipt proxying, zero-VRAM OpenVINO INT8 prose supervision, Ed25519 provenance-gated SQLite persistence, and syndication-aware RAG corroboration. By isolating signing keys from untrusted agent processes and binding natural-language action claims to RFC\,6962 and \texttt{AER-1} cryptographic receipts, \texttt{epistemic-guard} eliminates ungrounded side-effect narration and unauthorized memory writes on commodity CPUs in under \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.4.3/results/table3_heldout_supervision.json\#L33}{29.43}\,ms mean latency. Future work extends \texttt{mcp-proxy} to Streamable HTTP transports and integrates dense cross-lingual paraphrase clustering into the corroboration engine.
