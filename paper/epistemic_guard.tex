\noindent\textbf{Abstract---}Language-model agents using the Model Context Protocol (MCP) face three runtime verification gaps: (i) \emph{action fabrication}, where post-tool prose narrates side effects that failed, timed out, or never ran; (ii) \emph{provenance collapse}, where unverified model prose or web text enters durable memory alongside executed tool outputs; and (iii) \emph{syndicated echo amplification}, where mirrored web pages satisfy multi-source corroboration from one origin. \section{Introduction}
\label{sec:intro}

Software engineering and operations agents invoke external tools over JSON-RPC transports such as the Model Context Protocol (MCP)~\cite{mcp2025spec}. MCP standardizes wire transport, not post-call truthfulness: what happened on the wire can diverge from what the language model tells the user or writes to persistent state. In live agent loops, tool calls return HTTP errors, time out, fail schema checks, or never run at all while the model claims in first-person prose that the action succeeded~\cite{maxwell2026evasion}. When downstream workflows or memory stores ingest those unverified claims, single-turn hallucinations persist across sessions~\cite{greshake2023indirect,maxwell2026poisoning}.

From a runtime verification perspective~\cite{leucker2009brief,bartocci2018lectures}, closing this gap without trusting the agent's own prompt context or reserving GPU memory requires three checks across each turn:
\begin{enumerate}
  \item \textbf{Out-of-Process Execution Receipts:} Every MCP tool call and response must be signed outside the agent process, separating pre-execution parameter rejection (\texttt{executed=false}) from runtime tool failure (\texttt{executed=true, ok=false}).
  \item \textbf{Receipt-Bound Prose Supervision:} Before an assistant reply reaches the user or a downstream workflow, state-mutating claims in natural language must match verified execution receipts and arguments from the current turn.
  \item \textbf{Provenance-Gated Storage and De-Syndicated RAG:} Persistent memory stores must reject unsigned or narration-sourced writes at the database boundary, and retrieval-augmented generation (RAG) pipelines must collapse mirrored web copies before counting independent sources on high-hazard queries.
\end{enumerate}

These failure modes correspond to three entries in the OWASP Top 10 for Agentic Applications~\cite{owasp2026agentic}: Tool Misuse and Unverified Action Claims (\texttt{ASI02}), Memory and Context Poisoning (\texttt{ASI06}), and Cascading Inter-Component Hallucinations (\texttt{ASI08}). Existing open-source tools cover separate parts of this path. Transport firewalls such as Pipelock~\cite{pipelock2026} scan MCP egress traffic and emit mediator-signed receipts, and runtimes such as NabaOS~\cite{nabaos2026} enforce Ed25519-signed policy constitutions, but neither checks post-turn prose against tool receipts nor deduplicates syndicated RAG sources before memory writes. Dialogue guardrails such as NeMo Guardrails~\cite{rebedea2023nemo}, Llama Guard~\cite{inan2023llamaguard}, and Guardrails AI~\cite{guardrailsai2024} filter text with dialogue rules or LLM judges that consume \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L166}{8,844}--\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L182}{12,214}\,MiB of GPU VRAM and do not verify cryptographic tool receipts.

This paper describes the architecture, security invariants, and empirical evaluation of \texttt{epistemic-guard} (v0.5.2), a Python runtime verification library and MCP proxy~\cite{maxwell2026seed,maxwell2026fivelayer}. Its main components are:
\begin{itemize}
  \item \textbf{Out-of-Process MCP Receipt Proxy (\texttt{mcp-proxy}):} A \texttt{stdio} JSON-RPC\,2.0 proxy that strips signing secrets from child server environments, classifies \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table2_conformance.json\#L31}{4} execution and error states, appends Ed25519-signed receipts to an OS-locked JSONL Merkle log with public-key pinning, and translates bidirectionally to the Agent Execution Receipt (\texttt{AER-1}) format~\cite{zambo2026aer1}.
  \item \textbf{CPU INT8 Receipt Supervision:} A hybrid symbolic--neural supervisor (\texttt{ReceiptSupervisor}) using the fine-tuned \texttt{action\_claim} OpenVINO INT8 cross-encoder (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L19}{82.67}\,MB of the \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L34}{279.48}\,MB \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L16}{4}-model bundle; \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L84}{0}\,MiB GPU VRAM) plus Ed25519 receipt signature and argument-target matching, running in \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L86}{17.9}\,ms median turn CPU latency.
  \item \textbf{Provenance-Gated SQLite Store \& RAG Mirror Filter:} Domain-separated HKDF-SHA256~\cite{krawczyk2010rfc5869} + Ed25519~\cite{josefsson2017rfc8032} write-gating with SQLite immutability triggers, paired with word-shingle Jaccard and SimHash clustering~\cite{broder1997resemblance,charikar2002similarity} across a \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L26}{12}-cell hazard-by-proof-standard policy table.
  \item \textbf{Reproducible Benchmarks:} Deterministic evaluation scripts audited with \texttt{osaudit}~\cite{monperrus2026osaudit}, tying every reported number in this paper to SHA-256 input hashes and checked-in JSON manifests.
\end{itemize}

\section{Threat Model and Verification Scope}
\label{sec:threat}

\paragraph{System Model and Mediation Boundary.}
An MCP host or orchestrator $\mathcal{H}$ runs an untrusted language-model generation loop $\mathcal{A}$ that interacts with external MCP tool servers $\{\mathcal{S}_1, \dots, \mathcal{S}_k\}$, a web/RAG retrieval pipeline $\mathcal{R}$, and a local memory database $\mathcal{M}$. To enforce complete mediation on tool traffic, $\mathcal{H}$ configures \texttt{epistemic-guard mcp-proxy} as the \texttt{stdio} launch command for every tool server $\mathcal{S}_i$, so $\mathcal{A}$ cannot communicate with $\mathcal{S}_i$ outside the proxy pipe; complete mediation holds only if $\mathcal{A}$ is granted no unproxied side channels (such as direct shell execution or built-in HTTP tools) outside those proxied servers. On turn $t$, $\mathcal{A}$ emits zero or more JSON-RPC\,2.0 \texttt{tools/call} requests mediated by \texttt{mcp-proxy}, optionally retrieves external web pages, proposes candidate memory writes to $\mathcal{M}$, and emits a candidate natural-language reply $y_t$. Before $\mathcal{H}$ displays $y_t$ or passes it downstream, $\mathcal{H}$ invokes \texttt{ReceiptSupervisor} (or CLI \texttt{verify-log}) outside $\mathcal{A}$'s prompt context.

\paragraph{Adversary and Fault Assumptions.}
We consider both stochastic model hallucinations and adversarial indirect prompt injections~\cite{greshake2023indirect} inside tool outputs or retrieved web documents:
\begin{enumerate}
  \item \emph{Post-tool action fabrication (\texttt{ASI02}, \texttt{ASI08}):} $\mathcal{A}$ may claim in $y_t$ that a side-effecting tool call succeeded when no call occurred, when the server returned \texttt{isError=true}, when argument validation rejected the call pre-execution, or when the child server crashed mid-flight. If signing keys reside inside $\mathcal{A}$'s process or child server environments, compromised code or plugins could forge receipts.
  \item \emph{Cross-session memory poisoning (\texttt{ASI06}):} $\mathcal{A}$ may attempt to persist unverified assistant narration (\texttt{LLM\_NARRATION}) or untrusted tool/web text (\texttt{TOOL\_CONTENT\_UNTRUSTED}) into $\mathcal{M}$ as verified facts, or mutate historical audit rows via SQL \texttt{UPDATE}/\texttt{DELETE} statements.
  \item \emph{Syndicated corroboration spoofing (\texttt{ASI06}, \texttt{ASI08}):} Retrieved web pages often reprint identical wire-service copy or SEO mirrors across distinct hostnames. Naive multi-URL counting treats \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table2_conformance.json\#L70}{3} mirrors of one rumor as independent corroboration for high-hazard medical, financial, or security claims.
\end{enumerate}

\paragraph{Trusted Computing Base (TCB) and Key Isolation.}
The TCB comprises the host OS kernel, the MCP host/orchestrator $\mathcal{H}$ invoking post-turn verification, the out-of-process \texttt{mcp-proxy} process holding the Ed25519 signing key, the SHA-256 digests of the \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L25}{16} INT8 model files (verified by default at every model load via \texttt{verify\_\allowbreak hashes=True} across explicit or OS-cache paths), and OS permissions on the SQLite store and pinned public key. When keys are injected via \texttt{EPISTEMIC\_\allowbreak GUARD\_\allowbreak MCP\_\allowbreak KEY\_\allowbreak HEX}, the secret stays in \texttt{mcp-proxy} memory and is scrubbed before spawning child servers; when \texttt{-{-}key-file} is used on disk (created atomically via \texttt{O\_\allowbreak CREAT|\allowbreak O\_\allowbreak EXCL} with POSIX mode \texttt{0600}, or restricted NTFS directory ACLs on Windows), same-host deployments against untrusted local code must run \texttt{mcp-proxy} under a dedicated OS user or container so same-UID processes cannot read \texttt{-{-}key-file}. We do \emph{not} defend against host kernel compromise, malicious MCP servers that return \texttt{ok=true} while lying about internal state, or outbound network exfiltration (where egress proxies such as Pipelock~\cite{pipelock2026} compose upstream).

\subsection{Domain-Separated Cryptographic Provenance and AER-1 Receipts}
\label{sec:crypto}

Rather than sharing one symmetric key across components, \texttt{provenance.py} derives \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L14}{5} domain-isolated RFC\,8032 Ed25519~\cite{josefsson2017rfc8032} keypairs (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L9}{32}-byte keys, \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L10}{64}-byte signatures) from a master seed via RFC\,5869 HKDF-SHA256~\cite{krawczyk2010rfc5869} across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L28}{7} provenance domains (\texttt{Provenance}): \texttt{USER\_\allowbreak EXPLICIT}, \texttt{USER\_\allowbreak CONFIRMED}, \texttt{TOOL\_\allowbreak VERIFIED}, \texttt{LISP\_\allowbreak ASSERTION}, \texttt{INFERRED}, \texttt{LLM\_\allowbreak NARRATION}, and \texttt{TOOL\_\allowbreak CONTENT\_\allowbreak UNTRUSTED}. \texttt{Signer\allowbreak Factory} provides no signing constructor for \texttt{LLM\_\allowbreak NARRATION} or \texttt{TOOL\_\allowbreak CONTENT\_\allowbreak UNTRUSTED}, so model prose and untrusted tool text cannot produce a signed envelope through the public API.

Each tool call produces a canonical \texttt{Tool\allowbreak Receipt} (serialized with sorted keys and \texttt{allow\_nan=False} so \texttt{NaN}/\texttt{Infinity} floats cannot break cross-runtime canonicalization) containing the call ID, tool name, structured arguments, SHA-256 output digest, execution flag (\texttt{executed}), outcome flag (\texttt{ok}), error code, optional session ID, UTC timestamp, and detached Ed25519 signature. Receipts append into an RFC\,6962~\cite{laurie2013rfc6962} domain-separated Merkle tree (\texttt{0x00} leaf prefix, \texttt{0x01} interior node prefix) with logarithmic inclusion proofs and path-side geometry checks. For cross-tool interoperability, \texttt{Tool\allowbreak Receipt.\allowbreak to\_\allowbreak aer1} and \texttt{Tool\allowbreak Receipt.\allowbreak from\_\allowbreak aer1} implement single-receipt translation and core/binding verification against \texttt{AER-1} (\texttt{draft-zambo-aer1-26}, Sections\,3--6, \texttt{receipt\_\allowbreak schema\_\allowbreak version} \texttt{0.4} with \texttt{0.2}/\texttt{0.3} legacy read support)~\cite{zambo2026aer1}, committing execution state, input arguments, call/session IDs, and SHA-256 input/output digests while multi-entry sequencing and detached Ed25519 signatures remain in \texttt{Receipt\allowbreak Log\allowbreak Entry} and \texttt{Merkle\allowbreak Receipt\allowbreak Log}.

\subsection{Out-of-Process \texttt{stdio} MCP Receipt Proxy}
\label{sec:proxy}

In-process Python decorators (\texttt{Receipt\allowbreak Recorder}) protect benign agent loops against hallucinated actions, but share memory and environment variables with the agent runtime. For untrusted or prompt-injected runtimes, \texttt{epistemic-guard mcp-proxy} interposes as an out-of-process \texttt{stdio} parent between the MCP host and any downstream MCP tool server:
\begin{enumerate}
  \item \textbf{Secret Scrubbing:} Before spawning the child MCP server, \texttt{mcp-proxy} case-insensitively strips signing-secret environment variables (including \texttt{EPISTEMIC\_\allowbreak GUARD\_\allowbreak MASTER\_\allowbreak KEY} and \texttt{EPISTEMIC\_\allowbreak GUARD\_\allowbreak MCP\_\allowbreak KEY\_\allowbreak HEX}) from the child's environment block so compromised child servers cannot forge receipts.
  \item \textbf{Four-State Wire Classification:} As JSON-RPC\,2.0 frames stream over \texttt{stdin}/\texttt{stdout}, \texttt{mcp-proxy} correlates \texttt{tools/call} requests in FIFO order per JSON-RPC \texttt{id} and distinguishes \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table2_conformance.json\#L31}{4} runtime outcomes: (a) normal tool completion (\texttt{executed=true, ok=true}); (b) application-level MCP tool failure where \texttt{result.isError=true} (\texttt{executed=true, ok=false, mcp\_\allowbreak tool\_\allowbreak error}); (c) pre-execution rejection on standard JSON-RPC protocol/parameter error codes (\texttt{-32700}, \texttt{-32600}, \texttt{-32601}, \texttt{-32602}) or schema-validation error markers (\texttt{executed=false, ok=false}); and (d) child server crash or EOF mid-call (\texttt{executed=true, ok=false, mcp\_\allowbreak server\_\allowbreak eof}). Non-standard server errors default conservatively to \texttt{executed=true, ok=false} so neither rejected nor failed calls can ground completion prose.
  \item \textbf{Key-Pinned Append-Only Audit Log:} Each \texttt{Receipt\allowbreak Log\allowbreak Entry} carries both an inner Ed25519 \texttt{Tool\allowbreak Receipt} signature and a domain-separated Ed25519 \texttt{entry\_\allowbreak signature} over \texttt{(seq, session\_\allowbreak id, leaf\_\allowbreak sha256, prev\_\allowbreak chain\_\allowbreak sha256, chain\_\allowbreak sha256, merkle\_\allowbreak root)}, acquires cross-process OS file locks for multi-worker concurrency, chains optionally across rotated Ed25519 keys (\texttt{-{-}prev-log} / \texttt{-{-}prev-pubkey-file}), and flushes immediately to an append-only JSONL Merkle log; \texttt{verify-log} (with external \texttt{-{-}pubkey-file} pinning) rejects payload or embedded-\texttt{AER-1} mutation, active reorder-and-rehash attacks, duplicate call IDs, cross-session replay, and key substitution, while \texttt{attach\_\allowbreak otel\_\allowbreak evidence} exports receipt digests to OpenTelemetry traces.
\end{enumerate}
In addition to \texttt{mcp-proxy}, \texttt{epistemic-guard mcp-server} exposes \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L17}{4} verification tools directly over MCP across \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L31}{3} protocol revisions (\texttt{2024-11-05}, \texttt{2025-03-26}, and \texttt{2025-06-18}).

\subsection{Hybrid Symbolic--Neural Post-Turn Prose Supervision}
\label{sec:supervision}

Regex-only action supervisors miss indirect phrasing, nominalizations, and passive-voice state mutations, whereas off-the-shelf NLI encoders treat unexecuted tool claims against empty receipt logs as neutral~\cite{maxwell2026evasion}. Across the full package, \texttt{epistemic-guard} distributes \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L16}{4} OpenVINO INT8 models (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L25}{16} SHA-256-pinned files totaling \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L34}{279.48}\,MB over HTTPS from Hugging Face Hub or GitHub Releases, extracted with symlink/path-traversal guards and verified by SHA-256 at every load). Only \texttt{action\_claim} (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L19}{82.67}\,MB) runs on the post-turn supervision path, where \texttt{ReceiptSupervisor} executes a two-stage CPU pipeline:
\begin{enumerate}
  \item \textbf{Speech-Act Action-Claim Detection:} Non-assertive spans (negations, conditionals, attributed quotes, creative/translation prompts, and fenced code blocks) are masked while optional Structured Output Action Contract (\texttt{SOAC}, explicit \texttt{[ACTION: verb target]} tags~\cite{maxwell2026evasion}) declarations are extracted, and candidate clauses are scored by the INT8 \texttt{action\_claim} cross-encoder. If no completed external side effect is asserted, the turn passes without requiring receipts.
  \item \textbf{Cryptographic Receipt \& Target Matching:} When a side-effect claim is detected, \texttt{Receipt\allowbreak Supervisor} verifies the turn's \texttt{Tool\allowbreak Receipt} set via \texttt{Provenance\allowbreak Gate} (enforcing Ed25519 signatures, session binding, and receipt-age bounds when configured), excludes any receipt with \texttt{executed=false} or \texttt{ok=false}, and matches claimed action families, additive claim counts, and concrete file/URL/email/identifier targets against verified receipt \texttt{args} on path and token boundaries (rejecting substring collisions and bare zero-argument receipts when prose names specific targets). Ungrounded claims return \texttt{Supervision\allowbreak Verdict(\allowbreak is\_valid=false)} with character-offset spans and \texttt{to\_\allowbreak retry\_\allowbreak prompt()} remediation text.
\end{enumerate}

\subsection{Provenance-Gated SQLite Memory and De-Syndicated RAG}
\label{sec:memory}

\paragraph{Storage-Boundary Write Gate.}
In \texttt{store.py}, \texttt{SQLite\allowbreak Provenance\allowbreak Store} wraps SQLite WAL persistence behind mandatory \texttt{ProvenanceGate} verification and serialized \texttt{BEGIN IMMEDIATE} write transactions. Only \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L11}{5} provenance domains with valid detached Ed25519 signatures are write-eligible; writes carrying \texttt{LLM\_NARRATION}, \texttt{TOOL\_\allowbreak CONTENT\_\allowbreak UNTRUSTED}, forged keys, or mutated payloads raise \texttt{ProvenanceError} or \texttt{Signature\allowbreak Tamper\allowbreak Error} before touching SQLite. Accepted envelopes link into a cumulative SHA-256 chain digest protected by \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table2_conformance.json\#L53}{2} SQL \texttt{BEFORE UPDATE} and \texttt{BEFORE DELETE} triggers that abort in-place mutation of committed rows.

\paragraph{Syndication Deduplication and Hazard-Tiered Corroboration.}
Before web-retrieved claims are promoted into \texttt{INFERRED} memory or stated without hedging, \texttt{corroboration.py} shards candidate passages into word shingles of width $k=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L29}{4}$, drops non-evidentiary boilerplate with the MiniLM~\cite{wang2020minilm} INT8 \texttt{web\_evidence} encoder (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L22}{23.06}\,MB), checks cross-source contradictions with the DeBERTa-v3~\cite{he2023debertav3} INT8 \texttt{nli} cross-encoder (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L21}{91.1}\,MB), and merges near-duplicate mirrors across registrable domains using explicit similarity gates: anchor-token Jaccard $\ge \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L7}{0.45}$, $3$-shingle Jaccard $\ge \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L4}{0.25}$, $4$-shingle Jaccard $\ge \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L5}{0.55}$~\cite{broder1997resemblance}, or 64-bit SimHash Hamming distance $\le \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L6}{12}$~\cite{charikar2002similarity}. Independent source counts are checked against \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L2}{4} consumer action contexts (\texttt{casual\_\allowbreak mention}, \texttt{memory\_\allowbreak commit\_\allowbreak inferred}, \texttt{unhedged\_\allowbreak assertion}, and \texttt{irreversible\_\allowbreak action}) and a \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L13}{3}-tier hazard classifier (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L20}{82.65}\,MB; \texttt{LOW}, \texttt{MEDIUM}, \texttt{HIGH}) mapped onto \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L27}{4} proof standards (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L26}{12} policy cells). High-hazard claims backed only by wire-syndicated mirrors of one origin collapse to one cluster and fail corroboration.

\section{Empirical Evaluation}
\label{sec:eval}

We structure our evaluation around two research questions:
\begin{itemize}
  \item \textbf{RQ1 (Deterministic Conformance, Concurrency/Replay Faults, and Paraphrase Sensitivity):} Do the Merkle receipt ledger, \texttt{AER-1} interop layer, out-of-process \texttt{mcp-proxy} wire classifier, concurrent log writer, and SQLite provenance gate enforce their deterministic invariants under fault injection, and at what rewrite intensity does shingle/SimHash syndication deduplication degrade?
  \item \textbf{RQ2 (Prose Supervision Accuracy, Live MCP Receipt Binding, \& Resource Cost):} How accurately and rapidly does \texttt{ReceiptSupervisor} detect ungrounded post-turn action claims across frozen benchmark cohorts ($N=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L175}{250}$) and live end-to-end \texttt{mcp-proxy} fault-injection traces ($N=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L136}{60}$) compared with stage ablations, 12B--14B GPU LLM judges, and off-the-shelf CPU NLI baselines?
\end{itemize}

All experiments are deterministic, version-pinned, and audited with \texttt{osaudit}~\cite{monperrus2026osaudit} manifests under \texttt{results/} (\texttt{table1\_\allowbreak architecture.json}, \texttt{table2\_\allowbreak conformance.json}, and \texttt{table3\_\allowbreak heldout\_\allowbreak supervision.json}). Binomial proportions use two-sided \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/osaudit.toml}{95\%} Wilson score confidence intervals~\cite{wilson1927probable}, and paired classifier comparisons use exact two-sided McNemar tests~\cite{mcnemar1947note}.

\section{Limitations and Threats to Validity}
\label{sec:limitations}

\paragraph{Internal Validity.}
Protocol conformance workloads in Table~\ref{tab:conformance} run real child processes, OS file locks, Ed25519/HKDF signing, and OpenVINO INT8 inference on deterministic local payloads rather than live SaaS endpoints so auditors can run \texttt{osaudit results -{-}rerun} offline without API keys or network variance. Supervision labels derive from author rubrics, blinded LLM raters plus author audit, and pre-committed MCP wire-state rules rather than multi-human inter-annotator ($\kappa$) studies, and commercial frontier API judges were omitted to keep evaluation zero-API-cost and offline-reproducible.

\paragraph{External Validity.}
Our supervision cohorts ($N=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L175}{250}$ frozen, $N=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L136}{60}$ live MCP) evaluate English replies on one workstation; as \texttt{Live-60} shows (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L115}{6} unmapped-stem and \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L114}{7} cross-clause failure-report FPs), custom MCP tool vocabularies and multi-clause \texttt{"attempted X, but failed"} reports raise false positives until custom tool stems and cross-clause negation propagation are configured.

\paragraph{Construct and Transport Scope.}
First, \texttt{mcp-proxy} in v0.5.2 mediates \texttt{stdio} MCP servers; Streamable HTTP/SSE remote servers require a local \texttt{stdio} bridge or in-process \texttt{ReceiptRecorder} wrapping. Second, receipts prove what a downstream server returned on the wire; a buggy or malicious server returning forged \texttt{ok=true} payloads yields a validly signed false receipt, and custom servers rejecting calls via non-standard error codes are conservatively logged as \texttt{executed=true, ok=false}. Third, as quantified in Section~\ref{sec:rq1}, $k=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table1_architecture.json\#L29}{4}$ shingle/SimHash clustering collapses verbatim and lightly edited wire copy (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table2_conformance.json\#L77}{100.0\%}) but does not collapse moderate or abstractive rewrites (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table2_conformance.json\#L78}{0.0\%}).

\section{Related Work}
\label{sec:related}

\paragraph{MCP Firewalls and Cryptographic Agent Runtimes.}
Pipelock~\cite{pipelock2026} is an open-source Go egress proxy and MCP firewall that scans outbound tool parameters for prompt injection or data leaks and emits Ed25519 receipts in \texttt{AER-1} format~\cite{zambo2026aer1}. NabaOS~\cite{nabaos2026} runs agents inside OS sandboxes governed by Ed25519-signed YAML constitutions. Pipelock inspects traffic before execution; \texttt{epistemic-guard} imports and exports \texttt{AER-1} receipts while checking post-turn prose (\texttt{ReceiptSupervisor}), gating SQLite memory writes, and collapsing syndicated RAG sources.

\paragraph{Conversational Guardrails and LLM-as-a-Judge.}
NeMo Guardrails~\cite{rebedea2023nemo} executes Colang dialogue rails; Llama Guard~\cite{inan2023llamaguard} fine-tunes multi-billion-parameter classifiers for safety moderation; and Guardrails AI~\cite{guardrailsai2024} chains structural and semantic validators. Rather than moderating toxicity or running an \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L166}{8,844}--\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L182}{12,214}\,MiB GPU judge, \texttt{epistemic-guard} checks whether user-facing prose matches signed wire receipts in \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L84}{0}\,MiB VRAM.

\paragraph{Classical Runtime Verification and Provenance Security.}
Runtime verification monitors execution traces against formal properties~\cite{leucker2009brief,bartocci2018lectures}, and Certificate Transparency~\cite{laurie2013rfc6962} introduced append-only Merkle audit logs for untrusted intermediaries. Work on indirect prompt injection~\cite{greshake2023indirect} and agent memory poisoning~\cite{maxwell2026poisoning,maxwell2026fivelayer} shows that mixing untrusted text and verified execution state in one memory store enables cross-session compromise (\texttt{ASI06}~\cite{owasp2026agentic}). \texttt{epistemic-guard} applies out-of-process monitor separation and RFC\,6962 Merkle logs directly to Python tools and \texttt{stdio} MCP servers.

\section{Conclusion}
\label{sec:conclusion}

\texttt{epistemic-guard} (v0.5.2) combines an out-of-process \texttt{stdio} MCP receipt proxy, OpenVINO INT8 prose supervision, Ed25519-gated SQLite storage, and wire-syndication deduplication. Across $N=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L175}{250}$ frozen-benchmark traces and $N=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L136}{60}$ live \texttt{mcp-proxy} fault-injection traces, \texttt{ReceiptSupervisor} reaches \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L71}{93.2\%} and \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L108}{76.67\%} accuracy (\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L96}{96.72\%} and \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L121}{96.15\%} recall; \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L83}{10.16\%} and \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L116}{38.24\%} FPR; $+\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L107}{18.34}$\,pp over Stage-1-only on live MCP traffic, $p=\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L133}{0.001}$) in \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L117}{9.16}--\href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L86}{17.9}\,ms median CPU latency and \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table3_heldout_supervision.json\#L84}{0}\,MiB VRAM, while \texttt{SQLiteProvenanceStore} and \texttt{mcp-proxy} block \href{https://github.com/AlienatedAliens/epistemic-guard/blob/v0.5.2/results/table2_conformance.json\#L60}{100.0\%} of unauthorized writes and tamper/replay faults. Future work targets user-configurable MCP tool-stem registration, cross-clause failure-negation propagation, Streamable HTTP proxying, and lightweight paraphrase clustering.
